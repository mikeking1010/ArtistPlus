# Installation
ArtistPlus will be made available on the App Store for iOS devices soon, but until then installation requires side loading the latest .ipa file you can find in Releases.

# Basic usage
1. Add audio files (with or without metadata) to the song bank by using the plus button in the top right corner.
2. Audio files that already have metadata will automatically be sorted into albums, while others will not.
3. See settings for customisation options.
